# 🐾 你好呀，我是小y

欢迎来到我的小小角落！这里住着一只对数学、物理和计算机充满好奇心的猫猫。

喜欢漂亮的证明，也喜欢终于跑通的代码。遇到有趣的问题，会忍不住伸出爪爪：让我再想一会儿！

## 📚 学过的知识

### 🌿 数学：在定义与证明之间探险

学过实分析、抽象代数、点集拓扑和泛函分析，也接触过交换代数与代数拓扑中的一些内容。

- **代数结构**：群、环、域与模，理想和商结构，以及用同态连接不同对象的方法。
- **交换代数**：理想的扩张与收缩、根理想、局部化、张量积、正合列、准素分解、整扩张与赋值环。
- **分析与空间**：测度与 Lebesgue 积分、赋范空间与 Banach 空间、有界线性算子，以及 Hahn–Banach 定理、Baire 纲定理等基本工具。
- **拓扑与形状**：连续性、紧致性、连通性，以及同伦、基本群和用代数描述空间的思路。

喜欢漂亮的证明，也喜欢那些把不同知识突然连起来的瞬间。遇到「显然」两个字，猫猫有时会歪着脑袋多看一会儿。

### 💻 计算机：从代码到机器

学过 C 和 Python 的基础，也接触过数字电子技术、嵌入式系统与计算机系统的相关知识。

- **编程基础**：数据结构的基本使用、程序控制流程、字节串与文件处理。
- **底层机制**：数字逻辑、寄存器、时序、信息表示、机器级程序与处理器流水线。
- **性能问题**：数据依赖、缓存与计算量，以及程序写法和硬件执行方式之间的联系。

喜欢追问代码运行时究竟发生了什么，也喜欢把一个抽象想法变成能实际运行的小东西。

### 🧠 深度学习：从公式到模型

接触过神经网络、反向传播、批归一化（Batch Normalization）、残差网络（ResNet），以及扩散模型的基本思想；也了解过字节对编码（BPE）分词和注意力计算中的键值缓存（KV cache）。

对一个方法，既关心公式怎样写、代码怎样实现，也关心实验到底支持了什么结论。简洁的结构为什么有效，训练中的变化能否被解释，都是会让我忍不住多想一会儿的问题。

### 🌠 物理：公式背后的世界

接触过拉格朗日力学、哈密顿力学、作用量原理与诺特定理的一些基本思想，对用数学描述运动、对称性与守恒律的方式很着迷。

## 🌷 感兴趣的内容

- **抽象结构与几何**：交换代数、代数几何、拓扑与几何分析。喜欢看代数怎样记录空间，也喜欢看几何直觉怎样启发证明。
- **模型的原理与机制**：深度学习、生成模型，以及模型为什么能学习、泛化和生成。偏爱能把数学推理、具体机制与实验联系起来的问题。
- **高性能计算与科学计算**：算法效率、程序性能、计算机体系结构与物理计算加速。想知道一个计算任务为什么慢，以及怎样有依据地让它更快。
- **理论物理**：经典力学、量子力学，以及对称性、守恒律和数学结构之间的联系。世界的运行规则，实在很让猫猫好奇。
